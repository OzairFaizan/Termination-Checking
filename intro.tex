\chapter{Introduction}
Termination is a fundamental property of computer programs and a cornerstone of
formal verification. Infinite loops can lead to system failure, resource
exhaustion, and application crashes.

\begin{itemize}
    \item Halting problem
    \item Formal Verification and Proof assistants
    \item Very incomplete but sound, focuses on most common patterns
    \item Comparison with Stainless (SMT-solvers but more complete)
    \item Comparison with Rocq and other proof assistants.
    \item It is in a middle ground between strict and heavyweight termination
    checking used by proof assistants and lightweight for a "non-logical" language.
\end{itemize}
