\begin{abstract}

Determining whether a program will finish executing is,
in general, undecidable. Nevertheless, ensuring termination is crucial for
safety-critical systems, and the foundations of proof assistants.

This report presents the design and implementation of an opt-in termination
checker for the Scala 3 compiler, implemented as a \texttt{MiniPhase}.
Methods annotated with \texttt{@terminates} are verified to be terminating by 
leveraging structural decrease analysis of Algebraic Data Types (ADTs).

The checker can handle termination of recursive functions, mutual recursion
and while loops.
The user may use escape hatches about termination of some functions or
well-foundedness of ADTs.
If no errors were raised, the annotated method is guaranteed to terminate under
the assumptions made by any escape hatches.

\end{abstract}
